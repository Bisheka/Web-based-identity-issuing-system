# Web-based-identity-issuing-system
Y2S1-SE
🔹 System Features

 Citizen Portal

* Secure user registration and login
* Guided, multi-step application process for NIC / License / Passport
* Document upload with basic validation
* Real-time application status updates and notifications

Admin & Officer Portal

* Centralized dashboard to manage applications
* Document verification, approval, rejection, and feedback handling
* Role-based access control for admins and officers
* Issuance workflow with activity logging for accountability

💻 Technologies Used

HTML, CSS, Java, Spring Boot (MVC, Security, JPA), MySQL (XAMPP), Git

🎥 Demo Overview

* User side: application submission, document uploads, and status tracking
* Admin side: application review, verification, status updates, and issuance management
